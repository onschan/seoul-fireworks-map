# 2026 서울세계불꽃축제 관람 장소 지도

2026년 9월 5일 서울세계불꽃축제의 관람 장소 19곳과 한강 다리 7개를,
발사 구역까지의 거리·소리 지연·시야를 막는 지형과 함께 정리한 단일 페이지입니다.

## 특징

- 발사 구역(마포대교~한강철교 바지선)까지의 **실측 좌표 기반 거리 계산**
- 음속 343m/s 기준 **소리 지연 시간**
- 관람 지점에서 발사 구역까지의 **시선 위 장애물 판정** (한강 다리, 고층 건물, 구릉)
- 한강 다리별 **관람 가능 여부**
- 외부 라이브러리·타일 서버 없이 **순수 SVG**로 렌더링 (오프라인에서도 열림)

## 실행

빌드 과정이 없습니다. `index.html`을 브라우저로 열면 됩니다.

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## 주의

- 해안선과 섬 윤곽은 실좌표를 곡선 보간해 그린 **단순화 도식**입니다. 실제 이동은 지도 앱으로 확인하세요.
- 발사 구역은 2023~2025년 공식 안내와 현장 보도를 근거로 한 것으로, 2026년 배치도가 공개되면 갱신이 필요합니다.
- 세부 교통통제는 행사 직전 발표됩니다. 당일 아침 서울교통정보센터(TOPIS)를 확인하세요.
